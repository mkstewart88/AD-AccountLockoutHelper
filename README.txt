================================================================================
DOMAIN LOCKOUT HELPER & ROOT CAUSE INVESTIGATOR
Native Windows Domain Administrator Utility (Standalone Distribution)
================================================================================

This software is designed exclusively as a native Windows desktop application.
It communicates directly with Active Directory Domain Controllers via standard
Windows authentication (Kerberos/NTLM), Event Log APIs, and native quser.exe.
Zero external modules, zero software installation, and zero RSAT required.

================================================================================
HOW TO BUILD & RUN
================================================================================

STEP 1: RUN "Build-Executable.cmd" (DOUBLE-CLICK)
-------------------------------------------------------------------
1. Double-click "Build-Executable.cmd" in this folder.
2. The script locates the built-in Microsoft .NET Framework C# compiler (csc.exe)
   and compiles "Program-Code.cs" into "AccountLockoutHelper.exe" (~2s).
3. Prompts you to launch the compiled application immediately!

STEP 2: RUN "AccountLockoutHelper.exe"
-------------------------------------------------------------------
1. Double-click "AccountLockoutHelper.exe" generated by Step 1.
2. It launches the native Windows GUI app on your screen!
   (Zero external software or modules required; works on Windows 10/11
    and Windows Server 2016/2019/2022/2025).
3. You can copy "AccountLockoutHelper.exe" to any network share, USB drive,
   or domain-joined PC and run it directly.

MANUAL C# COMPILATION
-----------------------------------------------------------------------
If you want to compile or modify the source code yourself on any Windows machine:
1. Open Command Prompt as Administrator.
2. Run:
   %SystemRoot%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /out:AccountLockoutHelper.exe Program-Code.cs

BUILT-IN FORENSIC CAPABILITIES:
================================================================================
* Domain Lockout & Password Policy Auto-Discovery:
  Instantly discovers and displays the domain's Lockout Threshold, Lockout
  Duration (or manual unlock requirement), Reset Window, Maximum Password Age,
  and Minimum Password Length.

* Deep Account Security Profile & Timestamps:
  Displays Password Last Set (with elapsed hours), Password Expiration status,
  Last Bad Password timestamp and count, Last Successful Logon, Account
  Expiration date, and primary Security Groups.

* Smoking-Gun Diagnosis Engine:
  Automatically correlates recent password changes against lockout event
  timestamps. When a user updated their password within the past 72 hours and
  lockouts occurred afterward, the engine flags [CONFIRMED STALE CREDENTIALS]
  and pinpoints the offending devices.

* Account Unlock Accountability (Event 4767):
  Scans Domain Controller Security logs for Event ID 4767 ("A user account was
  unlocked") to display who unlocked the account (SubjectUserName), the Domain
  Controller that processed it, and the exact timestamp.

* Enterprise 802.1X Wi-Fi / NPS RADIUS Troubleshooting Playbook:
  Detects when lockouts originate from an NPS/RADIUS authentication proxy.
  Guides administrators to inspect NPS Event ID 6273 to identify the client's
  physical MAC address (Calling-Station-Id) and connected Access Point.

* Kerberos Bad Password Pre-Authentication Forensics (Event 4771):
  Scans for Kerberos Event 4771 to capture caller Client IP addresses (even when
  Event 4740 leaves caller computer blank) and decodes error codes (e.g. 0x18).

* Caller Host Connectivity & DNS Resolution:
  Runs fast ICMP Ping tests (with latency reporting), resolves DNS IPv4/IPv6,
  and tests caller device reachability without triggering EDR discovery alerts.

* Active vs. Historical Lockout Separation:
  "Currently Locked Out" shows only users actively locked right now.
  "Previously Locked Out" shows accounts with recent lockout events that are now
  unlocked. Accounts with 0 events and disabled accounts are cleanly excluded.

SECURITY & EDR / SENTINELONE COMPLIANCE:
================================================================================
AccountLockoutHelper.exe uses standard Microsoft system APIs:
  * System.DirectoryServices (LDAP queries for lockoutTime >= 1)
  * System.Diagnostics.Eventing.Reader (Event ID 4740 on Domain Controllers)
  * System.Net.NetworkInformation.Ping (ICMP reachability test)
  * System.Net.Dns (DNS IPv4 resolution)
  * quser.exe (Built-in Windows terminal session query)
  * shutdown.exe (Standard Windows remote restart)
No third-party DLLs, no unsigned external binaries, and no obfuscation.
Does NOT trigger SentinelOne, CrowdStrike, or Defender heuristics.
