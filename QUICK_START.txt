======================================================================
DOMAIN LOCKOUT HELPER - NATIVE WINDOWS UTILITY QUICK START
======================================================================

REQUIRED ENVIRONMENT:
- Must be executed on a domain-joined Windows machine.
- Requires Domain Administrator (or equivalent) credentials to query security logs, unlock accounts, and reset passwords.
- No RSAT installation required; uses native .NET interfaces.

----------------------------------------------------------------------
HOW TO BUILD & RUN:
----------------------------------------------------------------------

STEP 1: RUN "Build-Executable.cmd" (DOUBLE-CLICK)
   - "Build-Executable.cmd" is the single one-click compiler script.
   - It compiles Program-Code.cs into AccountLockoutHelper.exe in ~2 seconds.
   - Uses the built-in Windows Microsoft .NET C# compiler (csc.exe).
   - Zero software download, zero external modules, and zero installation required.

STEP 2: RUN OR DISTRIBUTE "AccountLockoutHelper.exe"
   - Double-click "AccountLockoutHelper.exe" generated by Step 1!
   - Instantly opens the native Windows desktop application.
   - Connects to Active Directory, queries domain lockout policies, detects
     domain controllers, and scans Security logs for Event 4740 (lockouts) and Event 4767 (unlocks).
   - Shows locked accounts, root causes, caller PCs/IPs, who performed unlocks, and QUSER sessions.
   - STANDALONE DEPLOYMENT NOTE: Once compiled, ONLY "AccountLockoutHelper.exe" is needed. You can copy just the .exe file to a network share, USB flash drive, or any domain-joined PC. All source code (Program-Code.cs), build scripts (Build-Executable.cmd), and documentation can be left behind or deleted.

OPTIONAL: MANUAL C# COMPILATION
   - Open Command Prompt as Administrator and run:
     %SystemRoot%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /out:AccountLockoutHelper.exe Program-Code.cs

----------------------------------------------------------------------
BUILT-IN ZERO-DEPENDENCY FORENSIC CAPABILITIES:
----------------------------------------------------------------------
1. Domain Lockout & Password Policy Auto-Discovery:
   - Displays Lockout Threshold, Lockout Duration, Observation Window,
     Maximum Password Age, and Minimum Password Length from Active Directory.

2. Deep User Account Security Attributes & Timestamps:
   - Displays Password Last Set (with exact hours elapsed), Password Expiration,
     Last Bad Password attempt and count, Last Successful Logon, Account
     Expiration, and Primary Security Groups.

3. Smoking-Gun Diagnosis Engine:
   - Automatically correlates recent password changes (within 72 hours) against
     lockout timestamps to detect and flag [CONFIRMED STALE CREDENTIALS].

4. Kerberos Bad Password Pre-Authentication Forensics (Event 4771):
   - Captures caller Client IP addresses (even when Event 4740 leaves caller
     blank) and decodes Kerberos status codes (0x18 = Wrong Password, etc.).

5. Caller Host Connectivity & DNS Resolution:
   - Runs fast ICMP Ping reachability tests, resolves DNS IPv4/IPv6 addresses,
     and tests caller device reachability without triggering EDR discovery alerts.

6. Remote Workstation Session Interrogation (QUSER):
   - Safely query active and disconnected user sessions, remotely log off
     stale sessions, or initiate a safe remote computer reboot.
