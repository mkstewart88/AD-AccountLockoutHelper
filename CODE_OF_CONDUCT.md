# Code of Conduct & Repository Scope

## Static Code Release & Maintenance Notice
This repository is published strictly as a static, unmaintained code release on an **"as-is"** basis. The author and contributors do not actively manage, moderate, or maintain community discussions, issues, or pull requests, and assume no duty of active stewardship, technical support, or patch obligations.

## Standards of Conduct
Anyone viewing, interacting with, or discussing this project or its public forks is expected to maintain standard professional conduct:

* **Mutual Respect:** Treat other professionals, administrators, and contributors with respect and professionalism.
* **Protection of Sensitive Data:** **Do not publish** sensitive credentials, private organization domain names, internal IP addresses, or personally identifiable information (PII) in public comments, issues, or pull requests.
* **No Support Expectations:** Do not demand technical support, feature additions, or bug fixes. This repository is provided without support, warranty, or maintenance obligations.
* **Inclusivity & Professionalism:** Refrain from harassment, derogatory comments, personal attacks, or inappropriate behavior in any community spaces associated with this project.

## Maintainer Discretion
Because this repository is provided strictly as-is:
* The author has no obligation to review, respond to, or resolve issues, discussions, or pull requests.
* Maintainers reserve the right to remove, edit, or reject comments, issues, or contributions that do not align with these standards or attempt to impose uncompensated support burdens.
